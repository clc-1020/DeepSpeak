# DeepSpeak
> 一个**纯客户端**的安卓 AI 陪伴应用：你自己填 API Key，她自己记住你、到点提醒你、主动找你说话，并且**有情绪、有关系、会想你**。
> 目前仅支持安卓
> 下载点这里↓↓↓
- https://github.com/clc-pro/DeepSpeak/releases
---

## 这是什么

一个AI 陪聊 App。重点在**提供情绪价值**：

- **她记得**：三层记忆（短期/长期/日记）按相关性注入每轮对话，不是把记忆存了却不用
- **她有情绪**：9 种情绪可共存、有强度、有诱因、30 分钟半衰；情绪会改变她**怎么说话**（不只是主动消息）
- **她跟你有关系**：关系深度只升不降，热络度会随久不联系变淡 —— 会想你，但不会忘了你
- **她主动**：环境/节日/追问/闲聊四类钩子，统一队列 + 精确闹钟；每天有限额、有勿扰
- **她省电**：进程不常驻，全靠 AlarmManager + WorkManager 唤醒

> 设计上把她当"她"而不是"它"——这也是情绪系统存在的理由。

## 核心特性

| 模块 | 能力 |
|---|---|
| **聊天** | 多轮对话 · SSE 流式逐字输出 · tok/s / 缓存命中 / 上下文占用显示 · 图片输入（≤10 张）· 会话列表与切换 · 人设可改 |
| **记忆** | 三层结构（短期/长期/日记）· 本地向量语义去重（bge-small-zh，512 维，余弦≥0.85 合并）· 淡忘衰减 · 容量淘汰（满 50 删 20，保护 24h 内与进行中任务）· 主对话按相似度注入（阈值 0.45，同主题只取 1 条）· **深度回忆**（说「记不记得 / 上次」这类过去的事时，专门放宽去翻更久的记忆；翻不到就如实说记不清、不编造）· 记忆管理界面可增删改 |
| **情绪** | 9 档（平静/开心/兴奋/得意/想你/低落/委屈/烦躁/心虚）· 多情绪共存（向量）· 强度+诱因+30 分钟半衰 · 零成本刺激闸门（只有明显情绪信号才调模型）· 注入主对话影响语气 · 主导情绪带颜文字 · 负面情绪有护栏（总和≤0.9、必须有诱因） |
| **关系** | 她跟你分生疏、熟悉、亲近三档，只升不降，靠聊得多、认识得久慢慢攒；久不联系，热络度会淡，但关系不会退回去。熟了会撒娇，也会把你们一起经历的暖心时刻悄悄记下来，越常想起越牢，久了才慢慢淡——你要是不想提，跟她说句"别提了"，她就收着，但不会删掉。**她找你的频率也跟着关系走**：刚认识三四个钟头冒个泡，越亲近越黏，两三个钟头就忍不住来找你。 |
| **提醒** | 「7 点叫我」一句话排期 · AlarmManager `setAlarmClock` 精确闹钟 · 开机自动重排 · 通知按钮「已完成」 |
| **追问（监督）** | 「从现在起监督我背单词」→ 到点问「完成了吗」· 恰好 5 次上限 · 30 分钟超时只重排不计次 · 多任务链并存（按任务文本去重）· 通知双按钮「已完成 / 再等等」· 点完成自动清理该任务的短期记忆 |
| **主动消息** | 统一待发队列（优先级：指令 5 > 追问 4 > 节日 3 > 环境 2 > 闲聊 1）· 2 小时 Worker 检查 · 五条纯规则闸门（勿扰/冷却 2h/每日上限/回复率降频/无钩子丢弃）· 勿扰期顺延而非硬发 · 通知标题随情绪变化 · 每日上限随情绪 ±1 |
| **环境与节日** | 时间/天气/位置规则（熬夜、降水、骤变、高温）· 生日纪念日按 MM-DD 重复 · 内置 7 个节日（含农历，构建期生成 2026–2036 JSON）· 同日去重 |
| **语音** | 云端 ASR 语音输入（长按录音 → 识别 → 回填可编辑）· 通知栏常驻「🎙 语音输入」快捷入口 · TTS 双通道（系统离线兜底 + 云端音色），朗读前自动剥离颜文字 |
| **省电与保活** | 进程不常驻 · WakeLock 5 分钟超时释放 · 国产 ROM 保活引导（自启动/后台白名单）· root 一键保活（可选） |
| **设置** | 顶部常驻「她的状态」速览卡片（心情 / 关系 / 热络度 / 情绪 / 判定理由，可 ↻ 刷新）· 模型与角色 · 主动消息 · 语音 · 系统 · 勿扰（区间 + 是否压提醒独立开关）· 人设默认收起（点击展开，显示字数）· 保存常驻右上角 |
| **外观** | 深色：纯黑 `#000000` 顶栏/聊天区/状态栏连成一片、气泡 `#333333` / 无框、主色 `#416EFB` · 浅色：白底 `#FFFFFF`、正文 `#191919`、主色 `#467CF6`/`#2F63D8`、用户气泡 `#ECF2FE` · **深浅均不跟随壁纸取色** · 顶栏 🧠 进记忆页 · 空对话页图标随深浅换（深=白鲸 / 浅=墨线鲸） |

## 技术栈

| 层 | 选型 |
|---|---|
| 语言 / UI | Kotlin · Jetpack Compose（Material3，compose-bom 2023.10.01） |
| 存储 | Room 2.6.0（7 张表，schema 导出在 `app/schemas`，`version = 7`） |
| 异步 | Kotlin Coroutines / Flow |
| 调度 | WorkManager 2.9.0 + AlarmManager（`setAlarmClock` / `setAndAllowWhileIdle`） |
| 网络 | OkHttp 4.12（含 SSE）+ Retrofit + Gson |
| 本地 AI | ONNX Runtime 1.16.3 + `bge-small-zh-v1.5`（512 维嵌入，90.5 MB，**不入库**，见下） |
| 安全 | EncryptedSharedPreferences（API Key 本地存储） |
| 模型服务 | DeepSeek 兼容 API（流式 chat / `json_object` / 云端 ASR / 云端 TTS） |

## 架构

```
app/src/main/java/com/companion/chat/
├─ domain/          纯 Kotlin，零 Android 依赖，可 JVM 单测（业务规则都在这里）
│  ├─ emotion/      情绪：状态/衰减/合并/拼装/闸门/颜文字/关系/热络度/想你
│  ├─ memory/       记忆：上下文块、容量淘汰
│  ├─ mood/         心情判定与提示词
│  ├─ proactive/    主动消息规则：闸门、分类、提示词、情绪上限微调
│  ├─ reminder/     提醒与追问链：解析、提取、去重、记忆匹配
│  ├─ alarm/ calendar/ environment/ power/ settings/ system/
│  └─ ContextBuilder.kt / ContextTrimmer.kt   上下文组装与裁剪
├─ data/            实现层：Room DAO/Entity、网络、prefs、嵌入、TTS/ASR、待发队列
├─ ui/              Compose 界面：chat / memory / settings / speech / permission / power / theme
├─ worker/          Worker 与 BroadcastReceiver（精确闹钟、开机、环境检查、记忆衰减）
├─ service/         通知栏常驻快捷入口（前台服务）
└─ CompanionApp.kt  手写装配（无 DI 框架，全部 by lazy）
```

**一次对话的数据流**

```
用户输入
 → ContextBuilder：稳定前缀（人设+能力+关系定位+长期摘要）+ 历史
                  + 尾部块（情绪状态 → 记忆块 → latest_reminder）→ 本轮 user
 → DeepSeek 流式 SSE 逐字显示
 → 落库；背景并行：记忆提取 / 情绪+心情判定（闸门命中才调）/ 追问判定
 → 回复按情绪追加颜文字（存库前）→ 语音朗读前剥离颜文字
```

**两个刻意为之的设计**

1. **会变的内容一律放尾部**（情绪块、记忆块）——放进 system 稳定前缀会让服务端前缀缓存整段失效，省下的 token 成倍吐回去
2. **衰减不靠定时任务**：情绪按 `updated_at`、热络度按 `warmth_updated_at` 在读取时现算，少一个后台任务就少一个耗电点

## 快速开始

**环境**：JDK 17、Android SDK 34、Gradle Wrapper（仓内自带）

```powershell
# 0) 下载嵌入模型（90.5 MB，不入库；走 hf-mirror 并校验 SHA-256）
pwsh -File tools/fetch_embedding_model.ps1

# 1) 单元测试 + 打包
$env:JAVA_HOME='<你的 JDK17 路径>'
.\gradlew.bat testDebugUnitTest assembleDebug --no-daemon
# 产物：app/build/outputs/apk/debug/app-debug.apk

# 2) 装机（-r 保留数据）
adb install -r -t app\build\outputs\apk\debug\app-debug.apk
```

**首次启动**：在「设置 → 模型与角色」填入自己的 API Key（Base URL / 模型名 / 人设），权限按引导授予（通知、精确闹钟、录音、定位）。

> ⚠️ 本仓库**不含任何 API Key、数据库或备份**。Key 只存在设备本地的 EncryptedSharedPreferences 里。

## 权限说明

| 权限 | 为什么需要 |
|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` | 调用你配置的模型 API |
| `POST_NOTIFICATIONS` | 提醒与主动消息 |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | 「7 点叫我」必须准点 |
| `RECEIVE_BOOT_COMPLETED` | 重启后自动重排提醒 |
| `WAKE_LOCK` | 闹钟到点短暂唤醒完成投递 |
| `FOREGROUND_SERVICE`(`_SPECIAL_USE`) | 通知栏常驻的语音输入入口 |
| `RECORD_AUDIO` | 语音输入（云端识别，用你自己的 Key） |
| `ACCESS_COARSE_LOCATION` | 天气/位置类环境钩子（可手动指定城市替代） |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 引导加入省电白名单，否则国产 ROM 会杀后台 |

## 已知限制

- **只能侧载**：APK 体积偏大（含模型后 200 MB+），不上应用商店
- **精确时间非绝对**：Doze 下 `setAndAllowWhileIdle` 可能晚几分钟；用户「强行停止」App 后系统会清掉全部闹钟，不补发
- **语音输入必须联网**（云端 ASR），离线不可用；单次上限 120 秒 / 8 MiB
- **回复率降频规则未接线**：`LOW_REPLY_RATE` 暂无数据源，永不触发（安全侧默认）
- **记忆的"任务清理"靠文本相似度**：`memory_short` 没有 reminderId 列，完成/放弃时的清理宁可漏删
- **厂商保活不保证**：国产 ROM 私有保活库只作可选尝试，不承诺
- 情绪细化（9 → 更多档）、关系影响主动消息节奏、情绪记忆在对话里主动引用 —— 规划中
